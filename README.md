# Smart Environmental Monitor 🌡️

## About
This project monitors ambient temperature and humidity using an ESP32 and DHT22 sensor. It was developed as part of my first-week internship task at Decode Lab.

## Components
- ESP32 development board
- DHT22 temperature and humidity sensor
- I2C LCD 16×2
- Wokwi simulator

## Features
- Temperature and humidity monitoring
- Sensor readings every 2 seconds
- Serial Monitor output
- LCD display for measured values
